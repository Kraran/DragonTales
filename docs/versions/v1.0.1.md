Les aventures de DragonTales se lisent maintenant **à voix haute**.

## Lecture à voix haute

- Chaque réponse du jeu est lue dès qu'elle s'affiche, ainsi que les indices des pièces magiques. Ni le nom du lieu ni ta commande ne sont lus.
- Dans **Microsoft Edge**, ce sont les voix neurales en ligne de Microsoft. Rémy multilingue est la voix par défaut, Andrew multilingue en anglais. Avec ces voix, la lecture est activée d'office.
- Dans un autre navigateur, ou sans connexion, la lecture reste désactivée et utilise les voix installées sur l'ordinateur.
- Dans **Options** : activer ou désactiver la lecture, choisir la voix, l'écouter, régler la vitesse et le volume. Tes choix sont gardés et valent pour toutes les aventures.
- Un bouton 🔊 sur chaque entrée du journal la relit.
- La musique baisse pendant que la voix parle, et une nouvelle commande coupe la lecture en cours.

`Jouer.bat` ouvre le jeu dans Edge quand il est installé : c'est la meilleure façon d'en profiter.

## Jouer

1. Télécharge `DragonTales-1.0.1.zip` ci-dessous et décompresse-le.
2. Sous Windows, lance `Jouer.bat`. Ailleurs, ouvre `DragonTales.html` dans un navigateur récent.

On peut aussi jouer directement dans le navigateur sur https://kraran.itch.io/dragontales

Les parties, sauvegardes et fins découvertes des versions précédentes sont conservées.

Le détail est dans [CHANGELOG.md](https://github.com/Kraran/DragonTales/blob/main/CHANGELOG.md).
